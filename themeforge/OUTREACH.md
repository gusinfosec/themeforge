## 3. Hacker News — Show HN

- **Title:** `Show HN: ThemeForge – one-click GNOME theming, no root, no system writes`
- **Body:**

> Hi HN! I built ThemeForge because theming GNOME has always meant hand-editing config files or trusting random scripts that write to system directories.
>
> It runs entirely in userspace: pick a curated Look (coordinated GTK theme + icon set + cursor), preview it live, apply with one click — and every change is snapshotted and restorable, so nothing is ever permanent.
>
> Tech: Python 3.10+, GTK4/Adwaita GUI + CLI, installs into per-user XDG directories, ships as a single wheel + tarball, works on GNOME 45+. This is my first open-source release — feedback on the design and the Look catalog is very welcome.
>
> https://payhip.com/b/n82Sq

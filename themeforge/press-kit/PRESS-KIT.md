## What it is

ThemeForge brings one-click theming to GNOME: pick a curated **Look** — a coordinated GTK theme, icon set and cursor — preview it live, and apply it. No root, no system writes, fully reversible.

## Key features

- **Curated Looks** — coordinated GTK theme + icons + cursor per Look
- **Live preview** — see the change before you commit
- **No root, no system writes** — installs into per-user (XDG) directories only
- **Fully reversible** — every apply is snapshotted and restorable
- **GUI + CLI** — GTK4/Adwaita desktop app and a terminal interface
- **Safe by design** — respects your system and your privacy
